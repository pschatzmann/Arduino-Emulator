Detailed Description

SSL Socket using wolf ssl. For error codes see https://wolfssl.jp/docs-3/wolfssl-manual/appendix-c.

SSL Socket using TinyTLS (TLS 1.3 client). The TLS session runs over the plain TCP connection of this socket.
