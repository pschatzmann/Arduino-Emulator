Detailed Description

ESP32/ESP8266/RP2040 compatible LittleFS which is a directory of the computer: LittleFS.open("/test.txt") opens LITTLEFS_ROOT/test.txt. The files which are uploaded to the microcontroller (e.g. the data folder of the sketch) can be used directly.
